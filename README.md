# ОчУмелые ручки 🎨

Платформа для записи на творческие мастер-классы (крафтовые воркшопы), разработанная на фреймворке Laravel. Проект выполнен с соблюдением стандартов промышленной разработки, включает в себя автоматическое тестирование и настроенный CI/CD пайплайн.

## 🚀 Функционал приложения
* **Аутентификация и авторизация:** разделение ролей (Мастер и Пользователь) с валидацией данных.
* **Личный кабинет пользователя:** просмотр истории и текущих записей на мастер-классы.
* **Личный кабинет мастера:** управление воркшопами (создание, редактирование), просмотр списка записавшихся участников.
* **Система бронирования:** валидация доступных мест, проверка временных промежутков и корректности дат.

## 🛠 Технологический стек и требования
* **Language:** PHP 8.3+ (с включенной строгой типизацией `strict_types=1`)
* **Framework:** Laravel 11.x
* **Package Manager:** Composer
* **Database:** MySQL / SQLite (для быстрого прогона CI тестов)
* **Стандарты качества:** Стилизация кода по стандарту **PSR-12** (Laravel Pint), статический анализ **PHPStan** (Larastan).

## 📦 Быстрый запуск и установка

1. Клонируйте репозиторий:
```bash
git clone [https://github.com/sakovaalina130-rgb/ouchumelye-laravel.git](https://github.com/sakovaalina130-rgb/ouchumelye-laravel.git)
cd ouchumelye-laravel
```

2. Установите зависимости PHP:
```bash
composer install
```

3. Создайте файл конфигурации окружения:
```bash
cp .env.example .env
```

4. Сгенерируйте уникальный ключ приложения:
```bash
php artisan key:generate
```

5. Запустите миграции базы данных и заполните её демонстрационными данными (seeders):
```bash
php artisan migrate:fresh --seed
```

6. Запустите локальный сервер разработки:
```bash
php artisan serve
```

## 🧪 Тестирование и Качество кода
В проекте настроено автоматическое тестирование основных модулей (авторизация, регистрация, логика личного кабинета и лимиты бронирования мест):
* **Запуск тестов:** `php artisan test` или `./vendor/bin/phpunit`
* **Статический анализ кода:** `./vendor/bin/phpstan analyse --memory-limit=512M`
* **Проверка стиля кода (Linter):** `./vendor/bin/pint --test`

## ⚙️ CI/CD Пайплайн
В репозитории настроен автоматический рабочий процесс **GitHub Actions** для веток `main`, `development` и `uat`. 
При каждом пуше или пулл-реквесте автоматически выполняются следующие шаги:
1. Инициализация окружения и установка зависимостей.
2. Прогон Unit и Feature тестов.
3. Статический анализ кода с помощью PHPStan.
4. Проверка код-стайла на соответствие стандарту PSR-12 (Laravel Pint).
5. Симуляция деплоя с ручным подтверждением (Deployment Simulation & Approval).
